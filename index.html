    Meta-Evolve documentation

    Meta-Evolve is an experimental Python library for programming evaluated improvement loops over versioned artifacts.

    Start with one deterministic checklist run. It is the maintained entrance for first-time users and contributors.

    For the shipped API, begin with the programming model. The architecture defines the domain invariants, and the milestones define the current implementation boundary.

    The Start here learning path is written as seven standalone chapters from basic search through source evolution. Each chapter includes its notebook's code, output interpretation, component responsibilities, failure boundaries, and answered questions; opening a notebook is optional.

    The executed notebooks in this site are the canonical files maintained beside their runnable examples. Their saved outputs are published as recorded evidence; documentation builds do not execute them again. Separately, the SealQA research notebooks are live-only and remain explicitly marked unexecuted until an authorized capture exists. The autoresearch example is a separate deterministic, executed guide to nested improvement with private selection and held-out checks.

    Read offline

    From a checkout, build and serve the complete site:

    uv sync --locked --group docs
uv run --group docs mkdocs build --strict
uv run python -m http.server --directory site

    Open http://127.0.0.1:8000. Repository collaborators can also download the meta-evolve-docs-<commit> artifact from a successful Docs workflow run on main. The artifact is private and retained for 14 days.
