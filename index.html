    Improve artifacts through evaluated evolution

    Status: Shipped.

    Meta-Evolve is a declarative Python library for a specific kind of program: one that improves a versioned artifact — a prompt, a config, a repository, a skill library — through bounded proposals, independent evaluation, and replaceable search, with every measurement, cost, and decision recorded.

    One complete loop

    This is a real, runnable improvement loop: it grows an empty checklist until all three items are done, then prints the winner and its ancestry.

    from meta_evolve import Budget, Greedy, Maximize, Task, run


ITEMS = ("outline", "draft", "review")


def complete_one(completed, _context):
    return (*completed, ITEMS[len(completed)])


def count_completed(completed):
    return sum(item in completed for item in ITEMS)


task = Task(
    evaluator=count_completed,
    objectives=(Maximize("completed", satisfy=len(ITEMS)),),
    budget=Budget(evaluations=4, trials=3),
)
result = run(
    task=task,
    seed=(),
    proposer=complete_one,
    search=Greedy(max_trials=3),
)


def main():
    print(list(result.best().value))
    print([list(trial.artifact.value) for trial in result.lineage()])


if __name__ == "__main__":
    main()


    uv run python examples/00_checklist/main.py
    Output
    ['outline', 'draft', 'review']
[[], ['outline'], ['outline', 'draft'], ['outline', 'draft', 'review']]

    Six parts made that happen, and they are the whole library:

    Part Question it answers In the loop above
    Artifact What can improve? An immutable checklist tuple
    Proposer How is a successor created? complete_one
    Evaluator What does better mean? Completed-item count
    Search Which parent is tried next? Greedy
    Budget How much work is allowed? 3 trials, 4 evaluations
    Run What evidence and result remain? best(), lineage(), summary()

    The proposer controls only candidate content. Evaluation, budgets, the recorded history, and any promotion into production stay outside its authority — that separation is the design.
