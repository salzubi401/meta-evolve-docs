    Meta-Evolve: improve artifacts through proposed, evaluated, recorded trials.

    The root package keeps the simple callable path small: define a task, bound it with a budget, and state what to maximize or minimize. The full durable vocabulary for policy authors and kernel code lives in meta_evolve.domain, and canonical serialization lives in meta_evolve.serialization.

    BudgetUnavailable

    Bases: RunError

    CapabilityError

    Bases: RunError

    A run's declared or requested execution profile is not honored.

    Raised for unverifiable component implementations (lambdas, closures, functools.partial, decorated wrappers, or callables with no resolvable module source), unregistered (role, name, version) lookups, and durable-local configuration that lacks a registry, durable storage, or a registered evaluator/proposer/policy. Also raised when storage is asked for an optional capability its components do not declare, such as enumerating runs through a non-RunIndex event store.

    ContextPolicy

    Bases: Protocol

    Select the exact bounded context bundle pushed to one proposer call.

    Only records committed strictly before the candidate trial's logical step are eligible; context facts themselves are never eligible. The kernel rejects a bundle that selects anything else or exceeds the declared bounds.

    register_context_policy(name, version, factory, *, deterministic, retry_safe, dependencies=())

    Register a module-level factory that rebuilds a context policy.

    resolve_context_policy(spec)

    Rebuild a context policy and confirm its declaration round-trips.

    register_artifact_type(codec)

    Register one artifact codec keyed by (kind, representation).

    Built-in keys are non-overridable — every codec offered for one is rejected, the built-in object included: a new decode under an old key would change the meaning of every artifact already committed under it, so different behavior needs a new key.

    resolve_policy(spec, *, budget)

    Rebuild a bound program from spec and confirm it round-trips.

    Constructs the unbound preset from the registered factory and spec.configuration, binds it against proposer/budget, and asserts the rebuilt SearchSpec equals spec exactly — the same check M4.4's resume relies on (there, budget is the recorded RunStarted.run_budget).

    Run

    Read-only queries over one committed local run.

    trials()

    Every committed attempt in commit order, seed trial first.

    The winner-shaped queries answer "what came out of this run"; this one answers "what happened in it", so it reports losers, failed proposals, and trials the budget never authorised for evaluation, and it is the one query that never raises NoSuccessfulEvaluation. Read TrialView.state to tell those apart.

    RunsNotComparable

    Bases: RunError

    Two runs disagree on a declaration their comparison is defined over.

    compare_runs ranks two runs only when they answer the same question: the same task, objective, budgets, initial artifact, and authorized components. declaration names the one that differed, so a caller can branch on it without parsing the message.

    SkillSet dataclass

    Bases: Mapping[str, str]

    An immutable mapping from skills/<name>.md to exact UTF-8 text.

    Storage dataclass

    Paired artifact and event storage, plus one all-or-none commit.

    is_durable is the explicit durability capability: later slices can gate on it (if not storage.is_durable: raise CapabilityError(...)) without inspecting concrete adapter types. Storage.durable(...) and a composed strategy that declares durable atomic commit set it True.

    durable(path) classmethod

    Wire durable storage into path (created if missing): one SQLite connection (events + artifact occurrence rows) shared with a content-addressed filesystem blob store under path/artifacts.

    compose(artifacts, events, *, commit_strategy, close=None) classmethod

    Compose independently implemented stores behind one atomic commit.

    The strategy declares whether its commit survives process restart; callers cannot separately forge is_durable.

    commit(run_id, expected_version, *, events, occurrences)

    Commit events and occurrences as one all-or-none unit.

    EventStreamConflict on a stale expected_version propagates unchanged, and nothing is written. See unit_of_work.py for the per-backend guarantee (durable: one SQLite transaction; in-memory: a locked copy-on-write swap; hand-built pair: local-only fallback).

    runs()

    Every run this storage holds events for, sorted by id.

    Identities, not Run objects: opening a run validates and replays its whole stream, and detail is already Run.summary()'s job. A listing exists so those queries stay reachable once the ids have scrolled out of a terminal, so it returns exactly what reopening one needs. The order is lexicographic by id and identical across backends; run ids are content-derived, so it is not chronological.

    Enumeration is an optional store capability (ports.RunIndex), declared by implementing it. A paired event store that does not is refused explicitly here — never reported as an empty store, which would be a silent capability downgrade.
